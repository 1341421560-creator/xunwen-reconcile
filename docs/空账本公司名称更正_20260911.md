# 空账本公司名称更正

首次启用时填写的公司全称已绑定到账本中。`config/defaults.json` 的 `label` 是下拉菜单简称，`name_hint` 是首次输入提示；修改这两项不会更正已绑定的公司全称。

## 操作

1. 更新软件并重新启动，在浏览器按 `Ctrl + F5` 刷新页面。
2. 选择填错名称的公司。在页面顶部，当前公司全称旁点击 **更正公司全称**。
3. 输入与银行户名、进项发票清单抬头一致的完整公司名称，勾选核对确认，再点击 **确认更正**。
4. 页面显示正确全称后，继续导入该公司的流水和发票。再次启动会读取更正后的名称。

适用于首次手动启用的公司，例如海思、东莞循文、华创星。默认摩德瑞特公司沿用原有配置绑定检查；这项功能不会修改默认公司配置或其他公司的账本。

## 允许更正的条件

该公司尚未导入过流水、发票或历史批次，没有已关联银行账户、匹配关系、冲突、迁移记录或旧版历史文件。保存过规则设置仍可以更正，原有规则会保留。

软件同时核对公司编号、原名称、账本版本与用户确认。名称已被其他账本使用、另一页面已保存新版本、备份失败或正式写入失败时，都会停止更正。已经导入数据的公司不能通过这个入口更换主体。

## 保存与备份

- 公司编号保持不变，账本版本增加一次，操作日志记录旧全称、新全称与备份校验值。
- 更正前的完整 JSON 快照保存在软件目录下的 `company-data/<公司标识>/ledger/name-correction-backups/before-<唯一编号>.json`。
- 备份成功后才原子保存正式账本。中间快照留在 `temp/companies/<公司标识>/`。
- 使用新版 **备份账本数据.cmd** 时，更正前快照会一起进入迁移包；恢复此迁移包也应使用支持本功能的新版软件。
- 已有历史导出文件保留当时的名称。软件更新包不包含真实账本、公司初始化信息或这些备份。

## 在另一台电脑更新

如果使用本次的 **公司全称更正补丁包**，先运行 **停止对账软件.cmd**，将补丁包内 `xunwen-reconcile` 文件夹中的内容复制到原软件目录（与 **启动对账软件.cmd** 同一级），替换同名程序文件。这个补丁不包含 `config/defaults.json`、真实账本和运行环境；适用于已经支持多公司的整合版，保留原有配置与数据。再运行 **启动对账软件.cmd**，在浏览器按 `Ctrl + F5`。

先运行 **停止对账软件.cmd**。如果使用 Git 克隆版本且没有修改受版本控制的文件，可在软件目录执行 `git pull --ff-only`，再运行 **启动对账软件.cmd**。

如果已经修改了 `config/defaults.json`，先保留该文件的副本；Git 提示本地修改会被覆盖时不要强制覆盖。也可以使用新版完整离线包，在新目录解压，通过原版的账本备份和新版的账本恢复功能迁移后，再更正名称。备份与恢复的命令文件名称以软件目录中的实际文件为准。
