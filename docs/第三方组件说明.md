# 第三方组件说明

仓库为了离线运行附带以下原始发行文件，其哈希和来源见 `config/runtime.json`。许可证从对应发行文件原样提取到 `docs/licenses/`，离线安装时也保留原包内的许可证和元数据。

| 组件 | 版本 | 原始发行物 | 许可证副本 |
|---|---|---|---|
| CPython | 3.12.10 | Python 官方 Windows x64 embeddable ZIP | `licenses/Python-LICENSE.txt` |
| xlrd | 2.0.2 | PyPI wheel | `licenses/xlrd-LICENSE.txt` |
| openpyxl | 3.1.5 | PyPI wheel | `licenses/openpyxl-LICENSE.txt` |
| et_xmlfile | 2.0.0 | PyPI wheel | `licenses/et_xmlfile-LICENSE.txt` |
| pypdf | 6.18.0 | PyPI wheel | `licenses/pypdf-LICENSE.txt` |

Python 包内的许可证也包括其随附组件的相关声明。此文不为业务源码另行指定开源许可证；源码的分发范围由项目所有者决定。
