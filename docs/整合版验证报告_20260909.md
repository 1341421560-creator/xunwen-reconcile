## 发现并处理的问题

- 深目录恢复暂存路径可能触发 Windows 路径长度限制：暂存改用短文件名，先检查目标冲突再写入。
- 精简 PATH 且继承了其他 PowerShell 配置时，内置模块可能无法加载：明确加入当前 Windows PowerShell 的内置模块目录。
- 后台服务可能继承启动调用者的标准句柄：改由独立进程模块显式绑定 stdin、stdout、stderr，服务不依赖启动窗口的管道。
- 测试中的长号码示例已替换为虚构值，避免携带源数据中的实际标识。

验证是在当前 Windows 电脑上用全新 clone、受限的子进程环境完成，未在第二台实体电脑、macOS、Linux 或 ARM64 上执行。离线启动不需要在线下载；Windows 本身、浏览器和目录写入权限仍是使用前提。
